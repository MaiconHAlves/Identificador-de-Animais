## 1. Trindade de Inteligência (Time de Desenvolvimento)
Seguindo o padrão de alta performance estabelecido no ecossistema NEXO, este projeto é operado por uma estrutura de inteligência híbrida:

1.  **Antigravity (O Arquiteto)**: Liderança de design, orquestração de módulos e planejamento estratégico.
2.  **Qwen 2.5 Coder 14b (O Operário Local)**: Execução de tarefas de volume, criação de boilerplates, serviços estruturais e funções utilitárias (Execução Local).
3.  **Claude Code CLI (O Cirurgião)**: Refatorações críticas, lógica de alta precisão e resolução de bugs complexos.

---

## 2. Escopo do Projeto
*   **Objetivo**: Dispositivo veicular para detecção e identificação de animais em pistas de rolagem.
*   **Abrangência**: Desenvolvimento completo de Hardware (sensores/processamento) e Software (IA/Interface).

## 3. Especificação Técnica (Hardware)
*   **Sensor Core**: Fusão de Sensores (Câmera Térmica + Câmera RGB).
*   **Visão Híbrida**: Uso de térmica para detecção de assinatura de calor (independente de luz) e RGB para confirmação visual e classificação de espécie.
*   **Processamento**: Edge Computing de alta performance (local).
